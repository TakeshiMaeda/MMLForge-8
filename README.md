# MMLForge-8

テキスト（MML）で書いて、その場で鳴らす。ブラウザだけで動くレトロ風BGM作成ツール＆再生エンジン。

MML（Music Macro Language）は `t120 l8 cdefgab` のように音楽をテキストで記述する伝統的な記法です。
MMLForge-8 は、その打ち込み・試聴・自動作曲・ゲームへの組み込みまでを、ビルド不要・依存ゼロの
バニラ JavaScript（Web Audio API）で提供します。音声ファイルは一切使いません。

## 使い方（エディタ）

`index.html` をブラウザで開くだけです。サーバもインストールも不要です。

- **試聴プレイヤー** — 行頭から始まる行が1トラック（複数トラックは同時再生で和音・伴奏）。
  行頭に空白を入れた行は前のトラックの続きで、トラック内で自由に改行できる。ループ対応。内容は自動保存。
  コメントは `;`（そこから行末まで。行の途中でも可）と `/* ... */`（複数行またぎも可）
- **チャンネルON/OFF** — トラックごとのチェックボックスで再生するチャンネルを選択。
  再生中に切り替えると曲を止めずに即ミュート/復帰
- **記述を最適化** — 選択範囲（未選択なら全体）を読みやすい書き方に整える。`l8` の効いている場所の
  `c8` → `c`（付点は残す）、今と同じ値の `l` の言い直しを削除、絶対オクターブ指定 `o5` → `>`
  （同じオクターブなら削除。3オクターブ以上の跳躍は `>` を並べるより読みやすいので `o` のまま）。
  `l` 指定が無い区間に4分音符があればトラックの頭に `l4` を置いて数字を省く（`c4 d4 e4 f4` → `l4 c d e f`）。
  トラックで**最初に現れる `o` は残す**（暗黙の初期値 `o4` に寄りかからせない）ので、それより前の
  オクターブは触らない。リピート `[ ]` の中は周回ごとに状態が変わらないときだけ書き換え、仕上げに
  音符列が変わっていないか検算するので音は変わらない
- **mml.js用にコピー** — コメントを除去し、継続行を連結して1行=1トラックに整形した状態でコピー。
  他プロジェクトの `mml.js` へ持ち出すとき用（後述の「境界」を参照）
- **自動作曲（ガチャ）** — 雰囲気（しずか/幻想/疾走/緊迫/明るい）×小節数×シードで曲を生成して即再生。
  スケール（明暗）・キー・テンポ・激しさ・リズムch・ハーモニーは個別に上書き可能。
  同じシード+同じ設定なら同じ曲を再現できます。生成結果を手で編集して仕上げる使い方が本命です
- **メロディ伴奏付け** — 1行目のメロディからキーとコード進行を推定し、ベース・アルペジオ等の伴奏を自動生成
- **メロディ追い足し** — 1行目のメロディの続きを生成して末尾に追加。キー・進行・音域・激しさは
  メロディから推定し、直前の音から自然につなげる（何度でも追い足し可）。
  同主調スケール変更（暗転/明転）・オクターブ上下・盛り上げ（小節ごとに激しく）・締め（終止形）も指定できる
- **ミニ鍵盤** — クリック / PCキー（Z行・Q行）で演奏。音色・音量・エンベロープを設定可能
- **演奏録音 → MML変換** — 鍵盤で叩いたリズムとメロディを、BPM・最小音符で量子化してMML文字列に変換
- **音声 → MML変換（採譜）** — マイク録音または音声ファイル（WAV/MP3等）から鼻歌・口笛・単音楽器の
  メロディを検出してMMLに変換。録音中は検出音名をリアルタイム表示。単音（モノフォニック）のみ対応
- **リズムパッド** — drumbit風の打ち込み式リズム入力。4トラック×16分×最大4小節のグリッドをクリックで
  打ち込み（各トラックに楽器プリセット: キック/スネア/ハット等を割り当て、o/v/@e を微調整可）。
  ループ再生で確認してMML出力・本編へ挿入。打点が重ならないトラックは1チャンネルにまとめて出力され、
  同一ステップの同時打鍵があるときだけチャンネルが分かれる

※ ブラウザの自動再生制限により、最初のクリック等の操作後に音が出ます。

## MML記法

| 記法 | 意味 |
|---|---|
| `c d e f g a b` | 音符。直後に `#` / `+` でシャープ、`-` でフラット（例: `c#` `b-`） |
| 数字・付点 | 音長。`c4`=四分 `c8`=八分 `c12`=三連 `c4.`=付点四分（省略時は `l` の値） |
| `r` | 休符（音長指定は音符と同じ） |
| `o4` / `>` / `<` | オクターブ指定 / +1 / -1（`o4` の `a` = 440Hz） |
| `l8` | デフォルト音長（初期値4） |
| `t140` | テンポBPM（初期値120。全トラックに書くこと） |
| `v0`〜`v15` | 音量（初期値10） |
| `q1`〜`q8` | ゲートタイム。8=音長いっぱい、小さいほどスタッカート（初期値8） |
| `@0`〜`@4` | 音色: 0=sine 1=square 2=triangle 3=saw 4=noise（初期値1） |
| `@e3,0,100,40` | エンベロープ: attack(ms), decay(ms), sustain(%), release(ms)。初期値 `@e3,0,100,40` |
| `[ ... ]3` | リピート3回（ネスト可） |
| `[ ... ]` / `[ ... ]0` | 数字なし・0 は無限ループ: 2周目以降ここから繰り返す（イントロ付きループ用。トラック末尾にのみ書ける） |
| `\|` | 小節区切り（再生には影響しない。見た目整理用） |

- noise（`@4`）は音程でバンドパスフィルタが動くため、`o2`=キック、`o5`=スネア、`o7`=ハットのような
  打楽器の打ち分けができます
- 無限ループの例: `t120 イントロ [本体]0` — イントロは1回だけ鳴り、以降は本体を繰り返します
  （ループ再生OFFのときは本体1回で停止）。複数トラックに書いた場合は最も遅い開始点が曲のループ開始点になり、
  短い無限ループ（ドラムパターン等）は曲の長さまで自動で敷き詰められます

## エンジンを自分のゲーム/アプリに組み込む

`mml.js` 1ファイルをコピーして読み込むだけです（依存なし・約280行）。

```html
<script src="mml.js"></script>
<script>
  // 再生（配列の各要素が1トラック。同時に鳴る）
  MMLPlayer.play([
    't120 l8 o5 @1 v11 cc gg aa g4',
    't120 l4 o3 @2 v9  c  e  g  e',
  ], { loop: true });

  MMLPlayer.stop();           // 停止
  MMLPlayer.setVolume(0.5);   // マスター音量 0〜1
  MMLPlayer.setTrackMute(0, true);  // トラック0を即時ミュート（false で復帰。再生中に有効）
  MMLPlayer.playing;          // 再生中か
  MMLPlayer.parse('t90 cde'); // 解析のみ → { notes:[{time,dur,midi}], duration, tempo, loopStart }
</script>
```

- 再生は lookahead 方式のスケジューラで、テンポが揺れません
- `play()` はパース失敗時に位置つきの `Error` を投げます（再生中の曲は守られます）

### エディタの機能と mml.js の機能の境界

**コメント（`;` `/* */`）とトラック分割（行頭/継続行）は `index.html` の機能で、`mml.js` にはありません。**
エディタは MMLPlayer に渡す前にコメントを空白へ潰し、テキストエリア1枚をトラック文字列の配列へ分解しています。

`mml.js` が読み飛ばすのは **半角スペース・タブ・改行・`|`** の4つだけで、それ以外の未知の文字は
`トラック1 位置5: 解釈できない文字です: ";"` のようなエラーになります。逆に言えば空白と改行は自由なので、
テンプレートリテラルで整形して渡せます:

```js
MMLPlayer.play([`
  t120 l8 o5 @1 v11
  cc gg | aa g4
`]);
```

| 記法・機能 | mml.js 単体 | index.html |
|---|---|---|
| 音符・音長・`o` `l` `t` `v` `q` `@` `@e` `[ ]` | ○ | ○ |
| 空白・タブ・改行・`\|`（無視される） | ○ | ○ |
| コメント `;` `/* ... */` | **×** | ○ |
| 行頭=新トラック / 行頭空白=継続行 | **×**（配列で渡す） | ○ |

エディタで書いた曲を持ち出すときは、再生ボタンの隣の **「mml.js用にコピー」** を使ってください。
コメントを除去し、継続行を連結して1行=1トラックに整形したものがコピーされるので、各行をそのまま
`MMLPlayer.play()` の配列要素にできます。エディタの記法ごと使いたい場合は、`index.html` 内の
`stripComments()` / `parseTrackBlocks()`（依存ゼロの純関数）も一緒にコピーしてください。

なお `@e3,0,100,40` の数値とカンマの前後だけは**半角スペースしか読み飛ばしません**（改行やタブを挟むとエラー）。

## 自動作曲エンジン（MMLComposer）

`mml-composer.js` を追加で読み込むと使えます（`harmonize` のみ `MMLPlayer.parse` に依存）。

```js
// 生成: 雰囲気×小節数×シード → MMLトラック配列
const { tracks, comment } = MMLComposer.generate({
  mood: 'intense',   // 雰囲気プリセット: 'calm' | 'mystic' | 'intense' | 'dark' | 'bright'
  bars: 8,           // 4 | 8 | 16
  seed: 42,          // 同じシード+設定なら同じ曲
  // ↓ 以下は省略可。指定すると雰囲気プリセットの値を個別に上書きする
  scale: 'minor',    // 'major' | 'minor' | 'dorian'（明暗）
  key: 'a',          // 主音の音名 'c'〜'b'（'f#' 'b-' 可。省略時はシードで決定。
                     //   キーだけ指定すれば同じ曲の移調版になる。メロディは完全移調、
                     //   ベース/アルペジオは音域を保つためオクターブ折り返しあり）
  tempo: 150,        // BPM直接指定（省略時は雰囲気のテンポ帯からシードで決定。
                     //   テンポだけ指定すれば同じシードの同じ曲を速さ違いで出せる）
  density: 2,        // メロディの激しさ 0(おだやか)〜2(はげしい)
  drums: true,       // リズムchの有無
  drumStyle: 'soft', // 'hard'(強め) | 'soft'(控えめ)
  harm: false,       // ハーモニートラック（5度ロングトーン）の有無
});
MMLPlayer.play(tracks, { loop: true });

// 伴奏付け: メロディMMLからキー・コード進行を推定して伴奏を生成
// opts は generate と同じ（ただし scale/tempo はメロディからの推定値を使うため指定不可）
const res = MMLComposer.harmonize('t90 l4 o4 a2 >c4< b4 a2 g2 ...', { mood: 'calm', seed: 1 });
MMLPlayer.play(['t90 ...メロディ...', ...res.tracks], { loop: true });

// メロディ追い足し: キー・進行・音域を推定して続きの小節を生成し末尾に追加
// opts: { seed, bars: 追加小節数(既定1), density: 0-2(省略時はメロディから推定),
//         scale: 'major'|'minor'|'dorian'(同主調転調。主音を変えず明暗を変える),
//         octave: -1|0|1(追加部分の音域シフト), build: true(小節ごとに激しく),
//         cadence: true(最後の小節を終止形にして締める) }
// 同じメロディ+同じ設定なら同じ結果。追い足すたびに元が長くなるので連続実行では毎回違う小節が出る
const ext = MMLComposer.extendMelody('t90 l4 o4 c e g e | d f a2', { seed: 1 });
// ext.mml = 追い足し後の全文, ext.added = 追加部分のみ, ext.warning = 端数警告 or null
```

アルゴリズムは定石ベースです: 雰囲気プリセット（スケール・テンポ帯・コード進行プール・音色）
→ コード進行を選択 → ベース=ルート、アルペジオ=分散和音、メロディ=強拍コードトーン＋弱拍スケール音
（声部連結）、最終小節は主音終止。詳細は `mml-composer.js` のコメントを参照してください。

## 動作環境

モダンブラウザ（Chrome / Edge / Firefox / Safari）。Web Audio API を使用します。

## 出自

ブラウザゲームのBGMを「音声ファイルなし・コード合成のみ」で作るために生まれたツールです。

## クレジット

外部ライブラリへの依存はありません。以下は本体に取り込んで利用している既存の成果です。

- **mulberry32**（擬似乱数, `mml-composer.js`） — Tommy Ettinger 作の小型PRNG。パブリックドメイン（CC0）扱いのスニペットで、決定的な曲生成（同じシード+設定なら同じ曲）に使用しています。
- **YIN法**（ピッチ解析, `mml-audio.js`） — de Cheveigné, A. & Kawahara, H. (2002) "YIN, a fundamental frequency estimator for speech and music" で発表された基本周波数推定アルゴリズムを、本プロジェクトで独自に実装したものです（音声→MML採譜に使用）。
