# PSGライクな8bit音源の音作り

# 1. 概要

現在のMML音源では、主に次の3要素で音の性格を作る。

1. **波形**
2. **エンベロープ**
3. **ゲートタイム**

それぞれの役割は次のとおり。

| 要素     | 主に決めるもの             |
| ------ | ------------------- |
| 波形     | 音の材質、明るさ、硬さ、倍音構成    |
| エンベロープ | 音の立ち上がり、減衰、持続、余韻    |
| ゲートタイム | 音符の実際の長さ、歯切れ、音符間の隙間 |

現在の音源では矩形波のデューティー比は50%固定で、ビブラート、ピッチエンベロープ、ポルタメントは使用できない。

そのため、音色の差は主に以下の要素で付ける。

* 波形
* ADSRエンベロープ
* ゲートタイム
* オクターブ
* 音量
* フレーズや音符の配置

# 2. 波形

## 波形指定

```mml
@0  ; sine
@1  ; square
@2  ; triangle
@3  ; saw
@4  ; noise
```

## 波形の性格

| 指定   | 波形       | 音の性格              | 主な用途              |
| ---- | -------- | ----------------- | ----------------- |
| `@0` | sine     | 丸い、透明、倍音が少ない      | 柔らかい低音、笛風、静かな電子音  |
| `@1` | square   | 太い、空洞感がある、8bitらしい | メロディ、ベース、アルペジオ    |
| `@2` | triangle | 丸いが少し芯がある         | 柔らかいリード、ベース       |
| `@3` | saw      | 明るい、鋭い、倍音が多い      | 強いリード、警告音、派手なフレーズ |
| `@4` | noise    | 音程でバンドパスフィルタの中心が動くノイズ | キック、スネア、ハイハット、爆発、風 |

## ノイズと音程

一般的なPSGのノイズと異なり、この音源のノイズは音程指定が有効で、音程に合わせてバンドパスフィルタの中心周波数が動く。オクターブを変えることで打楽器を打ち分ける。

```mml
@4 o3 c8  ; キック（低い帯域）
@4 o5 c8  ; スネア（中域）
@4 o7 c8  ; ハイハット（高域）
```

バンドパスは低い音ほど通す帯域が狭くなり、そのぶん音量が下がる。エンジンはこれをゲインで補償しているが、
補償には上限があるため**約375Hz（`o4` の `f` 付近）から下は補償しきれず、低いほど小さくなる**。
`o3` のキックで約4.6dB、`o2` では約7.6dB足りない（`o5` のスネア・`o7` のハットは補償が効くので影響なし）。
キックに `o2` ではなく `o3` を使うのはこのためで、`o2` まで下げると帯域の狭さと相まってかなり細くなる。
低い打楽器を前に出したいときは `v` を上げる（プリセットのキックは `v9` なので `v15` まで約4.4dB の余地がある）。

## 聴感上の強さ

同じ音量を指定しても、波形によって聴感上の強さは異なる。

```text
強い・派手

saw
square
triangle
sine

弱い・丸い
```

`saw`は特に強く聞こえやすいため、必要に応じて音量を下げる。

```mml
@3 v7 c4
```

## 波形比較用MML

エンベロープとゲートを固定し、波形だけを変更する。

MMLForge-8では行頭から始まる行が新しいチャンネル（同時再生）になるため、順番に鳴らす場合は2行目以降の行頭に空白を入れて継続行にする。

```mml
t120 o4 l4 v10 q8 @e3,0,100,40
  @0 c4 r4
  @1 c4 r4
  @2 c4 r4
  @3 c4 r4
  @4 c4 r4
```

# 3. エンベロープ

## 書式

```mml
@e attack,decay,sustain,release
```

各値の意味は次のとおり。

| 項目      | 単位 | 内容                     |
| ------- | -: | ---------------------- |
| Attack  | ms | 発音開始から最大音量になるまでの時間     |
| Decay   | ms | 最大音量からSustain音量まで下がる時間 |
| Sustain |  % | ゲートが開いている間に維持する音量      |
| Release | ms | ゲートが閉じてから無音になるまでの時間    |

初期値は以下。

```mml
@e3,0,100,40
```

これは、ほぼ即座に最大音量になり、音符中は一定音量を維持し、最後に40msの余韻を付ける設定である。

実装上の制限として、Attackは実際のゲート長（音符長 × q/8）の半分まで、Decayはその残り時間までに自動的に短縮される。長いAttackやDecayは、長い音符・大きい`q`と組み合わせたときに指定どおり効く。また、Releaseの最小値は約5msで、`0`を指定してもごく短い余韻が残る。

---

## Attack

Attackは、音の立ち上がりを決める。

|   Attack | 聞こえ方           |
| -------: | -------------- |
|    0～3ms | 即座に鳴る。硬い、電子的   |
|   5～15ms | クリック感を抑えた自然な発音 |
|  20～50ms | 柔らかい発音         |
| 50～150ms | ゆっくり膨らむ音       |
|  150ms以上 | フェードイン、環境音的    |

```mml
@e3,0,100,40
```

硬く素早い発音。

```mml
@e50,0,100,40
```

柔らかく、少し遅れて立ち上がる。

---

## Decay

Decayは、発音直後の最大音量からSustain音量へ下がる時間を決める。

|     Decay | 聞こえ方            |
| --------: | --------------- |
|       0ms | 音量変化なし          |
|   10～30ms | 硬い、クリック的        |
|  30～100ms | 弦を弾いたような音、短いベース |
| 100～300ms | 鐘、打撃音           |
|   300ms以上 | ゆっくり減衰する効果音     |

DecayはSustainと組み合わせて使用する。

```mml
@e3,80,30,40
```

80msかけて、最大音量から30%まで下がる。

---

## Sustain

Sustainは、ゲートが開いている間に維持する音量である。

| Sustain | 聞こえ方                  |
| ------: | --------------------- |
|      0% | Decay終了後に消える。打楽器、プラック |
|  20～40% | 最初だけ強く、その後細くなる        |
|  50～70% | 自然な減衰感                |
| 80～100% | 持続音、電子オルガン的           |

```mml
@e3,80,0,20
```

80msで完全に消える。

```mml
@e3,80,50,20
```

80msかけて50%まで下がり、その後は音符が終わるまで持続する。

---

## Release

Releaseは、ゲートが閉じてから無音になるまでの余韻を決める。

|   Release | 聞こえ方         |
| --------: | ------------ |
|    0～10ms | 硬く、すぐ切れる     |
|   20～50ms | PSGらしい短い余韻   |
|  50～150ms | 自然な余韻        |
| 150～500ms | 幻想的、残響的      |
|   500ms以上 | 長い余韻。音が濁りやすい |

```mml
@e3,0,100,0
```

ゲート終了時にすぐ音が切れる。

```mml
@e3,0,100,300
```

ゲート終了後も300msかけて音が消える。

---

## エンベロープの基本パターン

| 用途・性格   | エンベロープ            | 聞こえ方            |
| ------- | ----------------- | --------------- |
| 基準音     | `@e3,0,100,40`    | 素早く鳴り、一定音量を維持   |
| 完全な持続音  | `@e3,0,100,0`     | 電子オルガン的。切れ際は硬い  |
| 軽いアタック  | `@e3,40,70,30`    | 最初が少し強く、その後細くなる |
| 強いアタック  | `@e3,80,30,20`    | 弾いたような印象        |
| 短いプラック  | `@e3,80,0,20`     | 音符が長くても短時間で消える  |
| 硬いクリック音 | `@e0,15,0,0`      | 非常に短く硬い         |
| 柔らかい発音  | `@e30,50,70,60`   | ゆっくり立ち上がる       |
| 膨らむ音    | `@e100,0,100,100` | フェードインする持続音     |
| 長い余韻    | `@e3,40,70,300`   | 音を離した後も残る       |
| 減衰する効果音 | `@e3,400,0,100`   | ゆっくり消えていく       |

## エンベロープ比較用MML

波形をsquare、ゲートを`q8`に固定する。

```mml
t120 o4 l4 v10 q8 @1
  @e3,0,100,40 c4 r4
  @e3,40,70,30 c4 r4
  @e3,80,30,20 c4 r4
  @e3,80,0,20 c4 r4
  @e30,50,70,60 c4 r4
  @e100,0,100,100 c4 r4
  @e3,40,70,300 c4 r4
```

# 4. ゲートタイム

## 書式

```mml
q1
q2
...
q8
```

ゲートタイムは、音符の長さのうち、実際にゲートを開いて音を鳴らす割合を指定する。

| 指定   | 音符に対する長さ | 性格・用途            |
| ---- | -------: | ---------------- |
| `q8` |      8/8 | 音符いっぱい。持続音、レガート  |
| `q7` |      7/8 | わずかに区切る。標準的なメロディ |
| `q6` |      6/8 | 適度に歯切れがよい        |
| `q5` |      5/8 | 軽いスタッカート         |
| `q4` |      4/8 | 音符の半分。明確に短い      |
| `q3` |      3/8 | アルペジオ、短いベース      |
| `q2` |      2/8 | 強いスタッカート         |
| `q1` |      1/8 | 極端に短い。クリック、打撃的   |

## ゲート比較用MML

波形とエンベロープを固定し、ゲートだけを変える。

```mml
t120 o4 l4 v10 @1 @e3,0,100,0
  q8 c4 r4
  q7 c4 r4
  q6 c4 r4
  q5 c4 r4
  q4 c4 r4
  q3 c4 r4
  q2 c4 r4
  q1 c4 r4
```

## フレーズで比較

```mml
t120 o4 l8 v10 @1 @e3,0,100,0
  q8 c d e f g a b >c
  q6 c d e f g a b >c
  q4 c d e f g a b >c
  q2 c d e f g a b >c
```

# 5. ゲートとエンベロープの違い

短い音を作る方法には、大きく分けて2種類ある。

## ゲートを短くする

```mml
q2 @e3,0,100,0
```

音色自体は持続音だが、演奏として短く切る。

これはスタッカートに相当する。

## Decayで音を消す

```mml
q8 @e3,80,0,20
```

ゲートは長いが、音色自体が80msで消える。

これはプラックや打楽器のような音色になる。

## 違い

| 方法               | 意味           |
| ---------------- | ------------ |
| ゲートを短くする         | 演奏方法として短く切る  |
| DecayとSustainで消す | 音色自体が自然に減衰する |

音色プリセットを作る場合はDecayとSustainを使い、曲中で演奏表現を変える場合はゲートを使う。

---

# 6. ゲートとReleaseの関係

Releaseが長い場合、ゲートを短くしても音はすぐには消えない。

```mml
q2 @e3,0,100,0 c4
```

ゲート終了時にすぐ切れる。

```mml
q2 @e3,0,100,300 c4
```

ゲートは短いが、その後300msの余韻が残る。

ゲートだけを比較するときは、Releaseを0にする。

```mml
@e3,0,100,0
```

# 7. 役割別の音色例

| 音色        | 設定例                   | 特徴           |
| --------- | --------------------- | ------------ |
| 標準8bitリード | `@1 q7 @e3,30,75,30`  | 太く、軽いアタックがある |
| 硬いリード     | `@1 q5 @e3,20,60,10`  | 歯切れがよい       |
| 柔らかいリード   | `@2 q7 @e15,50,70,60` | 丸く穏やか        |
| 明るいリード    | `@3 q6 @e3,40,60,30`  | 派手で前に出る      |
| 持続音       | `@1 q8 @e3,0,100,30`  | 電子オルガン的      |
| 短いベース     | `@1 q6 @e3,70,20,20`  | 最初が強く短い      |
| 柔らかいベース   | `@2 q7 @e3,50,50,30`  | 丸く安定する       |
| プラック      | `@1 q8 @e3,80,0,20`   | ゲートに関係なく減衰する |
| キック       | `@4 o3 v9 q8 @e1,90,0,50`   | 低い帯域の短い打撃    |
| スネア       | `@4 o5 v8 q8 @e1,120,0,60`  | 中域のやや長いノイズ   |
| ハット(閉)    | `@4 o7 v6 q8 @e1,30,0,25`   | 高域の非常に短いノイズ  |
| ハット(開)    | `@4 o7 v6 q8 @e1,150,0,90`  | 高域の長めのノイズ。余韻がある |
| タム        | `@4 o4 v8 q8 @e1,100,0,60`  | キックとスネアの中間の帯域 |
| クラップ風     | `@4 o6 v8 q8 @e1,80,0,50`   | やや高域の短いノイズ   |
| 爆発音       | `@4 o2 q8 @e0,500,0,150`    | 長く減衰する低いノイズ  |

ノイズはオクターブでバンドパスの帯域が決まるため、`o`の指定が音色の一部になる。キック〜クラップ風の6種はリズムパッドのプリセットと同じ値（`v`・`q`を含む）。音の長さはDecayで作っているので基準は`q8`だが、`q`を小さくするとゲートがDecayを途中で切り詰め、短く硬い音になる（演奏表現として使える）。

# 8. 音色を作る手順

## 1. 音の役割を決める

* ベース
* メロディ
* アルペジオ
* 打楽器
* 効果音

## 2. 波形を選ぶ

| 目的        | 波形       |
| --------- | -------- |
| 標準的な8bit音 | square   |
| 柔らかい音     | triangle |
| 丸く透明な音    | sine     |
| 派手で強い音    | saw      |
| 打楽器、効果音   | noise    |

## 3. Sustainを決める

* 持続音：`60～100`
* 最初だけ強い音：`20～60`
* プラック、打楽器：`0`

## 4. Decayを決める

* 硬い音：短くする
* 弾いた音：`30～100ms`
* 長く減衰する音：`100ms以上`

## 5. Attackを調整する

* 硬い音：`0～3ms`
* 自然な音：`5～15ms`
* 柔らかい音：`20ms以上`

## 6. Releaseを調整する

* 歯切れを良くする：短くする
* 余韻を付ける：長くする

## 7. ゲートで演奏表現を付ける

* 滑らかにする：`q7～q8`
* 歯切れを良くする：`q4～q6`
* 強いスタッカート：`q1～q3`

---

# 9. まとめ

現在の音源では、音色は次の考え方で作る。

* **波形**で音の材質を決める
* **エンベロープ**で音自体の時間変化を決める
* **ゲートタイム**で演奏上の長さと歯切れを決める

特に重要なのは、DecayとSustainの組み合わせである。

```mml
@e3,0,100,40
```

一定音量の持続音。

```mml
@e3,80,30,20
```

最初が強く、その後細くなる音。

```mml
@e3,80,0,20
```

短時間で自然に消えるプラック音。

矩形波のデューティー比、ビブラート、ピッチエンベロープが使用できないため、現状では波形、ADSR、ゲート、音域、音量、フレーズの組み合わせが主な音作りの手段となる。
